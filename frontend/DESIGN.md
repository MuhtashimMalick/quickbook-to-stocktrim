# Design decisions: "Dispatch Ledger" (light theme only)

Warm paper, ruled hairlines, rectangular status stamps, serif display headings, mono identifiers.
All values live in `src/styles/tokens.css` (Tailwind v4 `@theme`); components use only token utilities.

- Colour: paper `#F6F3EC`, sheet `#FFFDF8`, rule `#DDD6C6`, ink `#1D1B16`, ink-muted `#5E5A4E`, accent (fletch green) `#1F5C4A`, hazard `#E0A100`.
- Status (text/tint): done, failed, skipped, excluded, running, aborted, dry-run (dashed border), interrupted, cancelled, partial (done with failures), unknown. `lib/status.ts` maps the API's status strings; `StatusStamp` takes an optional `label` (e.g. Late, Stale) that keeps the icon and colour. A status always shows icon + word + colour (`StatusStamp`).
- Type: Newsreader 600 (headings and the QuickBook wordmark only), IBM Plex Sans (UI, 15 px body, 13 px tables), IBM Plex Mono with tabular numbers (`Mono`) for ids, counts, times. Self-hosted via @fontsource, latin subsets only.
- Shape: 4 px spacing scale, radii 2/4 px, no card shadows (rules + paper/sheet contrast); only overlays use `shadow-overlay`. 36 px rows (`h-row`). Lucide icons at 16 px.
- Environment: TEST = thin accent top rule + `TEST` tag. PRODUCTION = ink banner with hazard stripes and a warmer paper (`[data-env="production"]`). The writes chip (solid/dashed) reads GET /settings.
- Motion (GSAP, `src/lib/motion.ts`): route enter = fade + 8 px rise, 0.25 s, stagger 0.05. Registered inside `gsap.matchMedia()` for `prefers-reduced-motion: no-preference`, so reduced motion shows the final state at once. No loops.
  Also: progress-bar fill tweens `scaleX` (0.4 s) and a status change gives the stamp a 0.2 s "press" (scale 1.15 to 1); both are inside `gsap.matchMedia()`, and reduced motion jumps to the final state.
- Accessibility: skip link, landmarks, one h1 per page, 2 px accent focus ring, polite live region (`LiveRegion`) announcing the page on navigation, login error receives focus.
- Data and time (F2/F3): TanStack Query hooks live in `features/*/api.ts` with keys in `api/queryKeys.ts`. `usePollInterval` polls every 2 s while a cycle or push run is running, every 30 s otherwise, and not at all while the tab is hidden; three failed refreshes in a row flag the page as no longer live (`FreshnessNote`). Events load incrementally (`after_id`, deduplicated). All times use Intl in the schedule's time zone (browser zone until /settings loads) with the UTC instant in the `title`; relative times use `Intl.RelativeTimeFormat`.
- Read-only screens: the API offers no cancel/resume/push over the web, so the UI explains and shows the exact CLI command (`CopyCommand`). Web Connector contact: recent under 15 min, late under 2 h, silent after, never connected when null (`features/overview/status.ts`).
- Entries (F4): sticky filter bar (outcome chips = icon + word + live count, a check mark when on), 36 px rows, identifier as a real button in mono with the QuickBooks name below. The detail is a Radix Dialog drawer (`components/Drawer`, 520 px token `container-drawer`): in 0.22 s, out 0.15 s (`useDrawerMotion`, inside `gsap.matchMedia()`; reduced motion is instant), focus returns to the row last viewed. No polling here: refetch on window focus, plus every 30 s while the selected run is running.
- Guard: `src/test/tokens.test.ts` fails on raw hex/rgb colours, arbitrary px/rem sizes or inline styles in component sources.
